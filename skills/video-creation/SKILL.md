# 在 PromptFrame 创作

使用当前连接的 `promptframe` MCP。客户端提供推理，平台管理作品、素材、持久任务、权限与用量。未连接时使用 creation-setup；已有可用连接不需要重复安装或更换 Token。

## 先读当前公开指引

先从实时工具、resources 或 prompts 目录发现项目入门，读取当前账号与项目可见的公开创作基线。标准资源只使用平台目录返回的 URI；支持 prompt 时使用其声明的参数。旧入口可使用目录中的 `platform_read_onboarding`，无需先创建作品或执行制作任务。

按返回的版本、正文摘要和公开合同导航开展创作；需要详细规则时继续读取相关主题，不从插件版本推断平台工具或参数。目录变化通知可更新可见工具；宿主未刷新时可用现有通用调用入口，并先读取目标的当前 schema。能力缺失时说明具体版本或原因，不猜内部工具、文件路径或权限。

## 接续同一作品

先明确用户要新建还是接续已有作品。使用项目和作品目录确定唯一目标；歧义名称先让用户选择。已有作品读取当前 Plan、Spec、素材、版本和在途任务，必要时沿游标补历史，不把一页结果当全历史。仅按用户意图创建新作品。

开始制作和编辑权交接由本人在 Studio 确认。使用平台返回的准确作品链接和状态；打开网页、工具参数或客户端推断不能代替确认。外部客户端继续同一作品，不另启网页导演。

宿主提供聊天身份，桥管理作品控制代次。不要在业务参数或 `_meta` 中填写身份、Token、controller 或 controlVersion。内容修改使用实际读取的 revision；失去编辑权后停止新写入，先读事实，按需要重新申请交接。恢复会话能否保留身份以宿主和平台实际结果为准。

## 制作与观察

按平台当前公开基线完成方案、素材、Spec、场景及旁白/时间线绑定。优先复用同作品已就绪素材；路径、外链或“已上传”文字不能代替平台返回的可信资产引用。真实时间尚未取得时保留平台的估计等级，不把估时写成精确对齐。

本机素材上传前先核当前作品和工具目录。用户已指定用于该作品的文件，或你在本次创作中专为该作品生成且知道确切输出路径的文件，直接使用本机上传入口，无需再请用户选择或确认。已有本机文件的来源或用途不明确时，先请用户指定。每次只读取一个确切文件，说明桥实际运行在哪台机器；远程桥看不到桌面文件时直接说明，不能把 Hosted 沙箱的 `local_path` 当作用户文件。沿平台目录的本机上传入口流式直传，保存原幂等键，用同一键查询、恢复或取消。断线或完成回执未知时观察原会话，不另建上传或重传未知分片。进度100%、校验通过和素材ready是不同状态；只有原平台返回的稳定资产在同项目就绪后才接入作品，不因此夺取编辑权或开始制作。

保存异步调用的 task、operation、幂等键和原期限。已受理或结果未知时只沿原身份观察，不因断线、等待超时、升级或切端重新生成。调用结果、可用素材、Spec 采用和费用分别读取；缺少费用事实不代表零费用。确认未受理后，才能按公开错误指引修正新请求。

检查保存后的正式引用，用 `render_contact_sheet` 的 `server` 来源。检查本地热更新或混合来源，先用 `studio_preview` 的 `read` 选中作品、页面和已加载版本，再以 `studio_preview` 来源请求同一组整片帧号。目标页缺共享时引导用户共享该标签页，刷新后重读页面。已受理任务沿原任务号观察。详见[多帧采样操作手册](https://github.com/ty-teams/promptframe-creation/blob/77bde90eb3abed06184f22afeac27c41db20336e/docs/preview-frames.md)。

要在 Studio 审片，沿 `studio_preview` 选择当前作品的准确页面和已加载版本，再控制同一页的播放模式、源帧选区与播暂停。以页面实际采纳的状态为准；网页上的后续操作优先于旧命令。播放控制不授予 Spec 编辑权，只有用户明确要求记为作品设置时才沿正常保存合同写入。

需要整片或区间 MP4 时，从实时目录读取 `platform_export_mp4` 的当前合同。Web 与 MCP 使用同一报价与订单：先核保存版本、源帧半开区间、固定输出帧率、金额和有效期，确认后只提交一个逻辑请求。失回执只读取该原请求，不能换键重复导出；旧平台不支持区间时明确说明，不能改成整片。历史、产物下载和费用按各自实际结果读取。

图片、音频和资源按宿主支持的标准内容显示。检查字幕节奏或转场时，从切点之前顺播原声，同时对照代表帧。需要最终编码、混音或下载文件时再检查正式导出。下载、解码、有声音轨、字幕同步及真人听感分别记录结果。

## 需要自定义组件时

先在平台目录检索现成组件并读取 schema，使用受管 `componentRef`。确需新组件时，使用项目入门返回的 `navigation.componentAuthoring`，按该平台已采用发行的组件 Skill、工具链 README、Authoring Guide 与 CLI 说明在独立作者项目开发。已安装 CLI 使用自己的随包文档及发行链接；选项与支持状态仍核当前平台 schema。导航元数据暂缺时可继续读取公开基线，使用已有 CLI 的文档。平台构建与授权就绪后再接回作品；本地文件、npm 包名和上传受理不是可用组件身份。组件上传凭据与创作 Token 用途不同。
