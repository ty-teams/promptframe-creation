通过 `promptframe` MCP 使用平台的当前工具目录。外部客户端提供自己的推理；平台不另起网页导演。先确认用户要做的作品、项目和已有事实，避免重复制作与收费。

## 连接与选择作品

未连接时按仓库 README 运行 setup，提供用户选择的平台 API 地址。凭据只交本地 setup 的安全输入，不写聊天、源码、命令行参数或 MCP 业务参数。创作 Token 与组件上传凭据用途不同，也不是 OAuth `mcp login`。

使用平台项目和作品列表选择目标。新作品使用稳定的幂等请求键；已有作品先读取最新历史、Plan、Spec、素材和在途任务，再申请编辑权，由本人在 Studio 确认。不要修改已有作品的运行时来换端。断线和思考不代表释放编辑权。

作品读取默认返回一页历史和当前文档的版本/摘要，不代表完整历史或完整 Spec/Plan。需要正文时，按平台当前 schema 显式选择所需文档；更早消息沿返回的游标继续读取。引用单条消息或原工具调用时使用其稳定身份，不把近期页当全历史，也不为补读重派业务。

## 准备与方案

先复用已有素材和合适的已受检组件。外部客户端可用自己已有的调研、图像或本地创作能力，平台外用量不冒作平台计费；不要为省步骤而重复生成已经完成或结果未知的订单。

用平台的 brief 上报能力保存外部需求/交接说明，明确是客户端上报。没有上报的外部聊天、思考或本地代码仍未知，不能伪造为平台历史或用户已确认原话。

读取当前业务目录与 exact schema 后调用工具，不在本 Skill 维护参数副本。CreativePlan 独立创建/读取/修改，保留完整需求、导演方案和可信来源。其它业务调用引用已保存的方案，不夹带另一份 Plan 或反向覆盖它。

上传自有素材后，等平台确认受管状态 ready，并使用返回的稳定 assetRef。文件路径、外部下载地址和“已上传”提示不能替代资产就绪。外部自己生成的图片不会凭上传自动产生平台原生图服务费。

## 开工、费用与异步

正式制作需要已保存 Plan 和平台本人点击开始。把平台返回的确认状态与准确 Studio 入口交给用户；工具参数、已打开网页和 URL 都不能代为批准。批准后由当前外部客户端继续，不启动第二个网页导演。

每次新动作使用当前编辑权 controlVersion 与平台作品 revision。失权后停止新派发和写入，重新读事实；不要把旧整份 Spec 覆盖当前作品。预算沿同一作品的原有段，不把换工具、换端或新 task 当作重置额度。

长工具返回持久 task ID；保存它和原订单身份，用有上限的 wait/状态读取接续。RPC 结束或没再 poll 都不取消原订单。网络结果不明时先查询原 task，重试用同一个幂等键，不自动重派。保留原输入、期限和未知事实。

费用以平台原 receipt/账务读面为准，区分实计、预留、待结算和未知。成功媒体、工具终态和财务终态可以不同；未知不是免费。平台工具调用与外部自费推理/素材费用分开说明。

## 接回与完成

交接前可保存简明外部报告，随后释放自己当前代次的编辑权。没有报告也不阻止本人从 Studio 接回。旧订单可按原事实收尾、晚结果入素材与原账；旧客户端不能覆盖新 Spec。

反馈只描述实际可见文字、工具结果、媒体就绪和导出状态，不补写模型思考或虚构进度。完成时核方案、素材引用和真实输出；需要云端 MP4 就等平台输出 ready，再把可访问结果交给用户。技术完成与本人视听验收分别说明。
