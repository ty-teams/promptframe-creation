# 在作品里检查几帧画面

先确定要回答的问题，读出项目、作品、当前保存版本和帧率。检查同一个切点时，例如选择前一帧、切点、后一帧，两种来源都用相同的整片帧号。第一帧是 0。听感、连续播放和最终文件分别验。

| 想看什么 | 从哪里看 | 开始前确认 |
| --- | --- | --- |
| 保存后的字幕、构图或固定组件在正式渲染端的画面 | `render_contact_sheet` 的 `server` 来源（默认） | 目标版本与已保存引用匹配，可以关闭网页 |
| 刚改的一行本地组件、混合来源或用户页面实际显示的结果 | 同一工具的 `studio_preview` 来源 | 在目标作品读出页面 ID、来源模式、作品版本及组件实际加载版本。该页保持在线并共享对应标签页 |
| 换行时声音是否跟得上、转场中是否闪一下 | 在 Studio Play 顺播这一小段，结合切点前后的采帧 | 使用原旁白，在镜头前开始播放。记录听到的词、看到的变化和帧号 |
| 最终编码、混音、下载文件 | 按需要检查正式导出 | 单张图、合图和无声播放不能验证最终文件的音画 |

## 从 Agent 发起

1. 从当前项目的实时目录读取 `render_contact_sheet` 的 schema。检查保存版时传入项目、作品、实际修订和所需的 `frames`。例如一个切点在整片第 120 帧，可以请求 `[119,120,121]`。也可以让工具按场景取代表帧。
2. 检查 Studio 时，先调用 `studio_preview` 的 `read` 动作，选中目标作品的准确 `pageId`。确认要求检查的组件已加载并应用到这一版画面。用同一组帧号，显式传 `source: "studio_preview"` 和该页面 ID。多个在线页面时按实际作品、页面、版本区分。
3. 如果收到任务号，保留原任务号，按工具的观察参数回查。任务完成后打开实际合图，按标出的帧号检查。读取超时或结果待确认时继续观察原请求。图片过期且仍需要看图时，重新发起有明确目标的新采样。

## 页面需要用户配合时

目标页提示共享时，点击共享按钮，在浏览器选择器中选择该 Studio 标签页。已连接的本地开发工程和浏览器共享是两种独立状态。刷新后，重新读取页面身份和共享状态。页面还记得开发工程时，通常只需重新共享。页面内的提示随已部署版本提供，也可以使用工具栏的共享入口。

找不到页面，先打开目标作品再读页面目录。页面失联、用户拒绝、组件还在加载、HMR 过程中版本改变或画面被遮挡时，保留任务返回的原因和已查明的阶段。重新采样前先检查目标页和版本。服务端图不能证明本地代码已经生效。结束后核对原播放位置与播放态。

## 把结果交给下一位作者

记录作品、保存版本、来源、实际加载的组件版本、帧号和看见的变化。例如“同一版本第 119 帧为旧字幕，第 120 帧换到下一行，第 121 帧首字高亮”。有声检查同时记下对应的原声和时间精度。合图是临时检查结果。需要复查时保留上述条件，并在授权范围内保存所需的小样。
