# 0.2.1

本版提供自包含的 Codex 插件运行文件、用户级 connect 安装、setup/video-creation 两类 Skill、独立环境/账号 profile 和版本目录升级。已有有效凭据复用，旧桥与旧文件不因升级被覆盖。使用方法见[安装说明](../installing.md)。具体发行及宿主验证范围仍按 registry、固定标签和真实安装结果核实。

0.2.0 的固定标签保留。其正式 run [39998826031](https://github.com/ty-teams/promptframe-creation/actions/runs/39998826031) 在“安装依赖之前验证标签”步骤因提前导入 esbuild 失败；npm ci、打包、artifact 上传和 publish 均未执行。0.2.1 将构建依赖延迟到 pack 调用内，并增加无 node_modules 的标签预检回归。发布 job 继续只用 Node 和原已核 artifact，不更改 OIDC、账号信任或既有标签。

历史0.1.1基础包及其固定来源保持。插件注册、平台连接、宿主加载与完整创作分别验证；本版说明不代表所有操作系统或完整作品验收通过。
