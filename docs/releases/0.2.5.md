# 0.2.5 项目入门与公开说明

本版已从固定 `creation-v0.2.5` / `6d23a4689d777464f42fe0e0f95e31f4f5df01d0` 沿既有 GitHub Actions OIDC 流程发行，官方 registry 版本及 latest 均为0.2.5。公开 tgz 与同一受检 CI artifact 字节一致；既有0.2.4包和标签保留。Studio 安装指引仍以对应平台版本实际提供的固定推荐为准，不自动追踪 latest。

- 创作 Skill 在创建作品前先发现项目只读入门，由平台返回当前公开基线、版本摘要和既有组件作者工具链导航；不复制基线正文。
- 宿主桥支持 Skill 目录和说明读取，使用服务端控制版本并检查作品读取权限。显式 use 需要编辑和执行权限。
- 创建、读取和交接作品时，提供平台返回的 studioUrl；可以按用户要求打开链接，不会自动启动导演或接管作品。
- 继续复用安全凭据，支持独立 profile。安装后在同一主机打开 Local 新聊天，检查两个 Skill 与 MCP 是否加载。

受影响桥接、版本绑定、同一 tgz 的隔离 npm 与纯解包运行，以及公共固定包入口已分别核验。项目入门和说明读取需要相容的平台服务；安装后在同一主机的新聊天中检查插件加载状态。
