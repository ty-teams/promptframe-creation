# 0.2.5 项目入门与公开说明候选

这是可审候选，尚未发行。实际公开安装仍使用 Studio 推荐的0.2.4；候选分支同步 package、lock、插件、npm目录和 CLIENT_VERSION，正式发布须沿发布手册使用新标签。既有0.2.4包和标签保留。

- 创作 Skill 在创建作品前先发现项目只读入门，由平台返回当前公开基线、版本摘要和既有组件作者工具链导航；不复制基线正文。
- 宿主桥支持明确的 Skill 目录和说明读取，在原作品读取权限与当前服务端工具合同内使用真实控制版本。显式 use 仍要求编辑及执行准入，不能借读版本升权。
- 创建、读取和交接时原样交给用户服务端 studioUrl；仅按用户要求及宿主真实能力打开，不自动启动导演或接管作品。
- 复用原安全凭据、安装发现、未知登记回程、两 profile 和 Local 新聊天四态指引，不改个人安装或活动桥。

候选检查覆盖受影响桥接、版本绑定、同一 tgz 的隔离 npm 与纯解包运行。平台新入门及公开说明能力仍需相容服务部署；候选通过不代公共 registry、真实个人宿主加载或完整制作验收。
