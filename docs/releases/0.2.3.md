# 0.2.3 — 安装版本与运行环境检查

- `connect` 返回实际 `version`、指令的 `requestedVersion` 和 `versionStatus`。同版本复用，已装更新版本保留，不默认降级。
- 受管旧版本沿独立版本目录升级，旧代码、凭据及原任务保持。复用时实际检查已记录 Node 和 CLI；缺失或不可用时返回明确恢复指引，较新版本可用当前 Node 准备新桥。
- 官方 npm 来源旧插件返回 `installation.npm_plugin_upgrade_required`，不再误报已升级。Codex CLI 0.160.0 升级 npm 插件会删除旧缓存，因此不能自动保证活动桥保留；按[安装说明](../installing.md)在活动桥结束后升级原插件并核回版本。
- 设置和创作 Skill 统一指向固定推荐版 `connect`；`setup` 只处理凭据。推荐版本由 Studio 连接入口提供，没有后台自动更新守护程序。

以上不代表每台用户 Desktop 已加载新版，或完整视频创作旅程已验收。首次安装/升级后仍需按宿主正常方式重载，并确认两个 Skill 和 MCP 工具同时可见。
