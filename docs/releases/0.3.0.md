# 0.3.0

支持 Codex 与 Claude Code 使用同一平台创作授权。两个宿主分别登记，命名 profile 隔离环境与账号；默认客户端名称按宿主显示，自定义名称保留。

- Claude Code 通过官方用户级插件命令安装。插件命令不可用时可准备独立 MCP 和两份用户 Skill，安装结果明确区分这两种方式。登记回程未知时先核原身份，不重复登记或覆盖其它配置。
- 桥从平台目录发现工具和访问类别，转发标准 text、image、audio、resource_link、resource 及结构化结果。媒体表示按宿主实际声明选择，预算按序列化 UTF-8 核验；超限降级不会重复执行业务。
- 公开创作基线可通过版本化 resources/prompts 读取，逐次检查账号和项目权限。正常交互观察到目录变化后发送相应通知，不在空闲期轮询平台。
- 新会话按平台最低／推荐桥版本选择固定官方包，校验完整性并使用私有缓存；`--bridge-version X.Y.Z` 可锁定兼容版本。活动桥不被替换，已受理任务保持原身份与期限。

需要 Node.js20+ 和相容的平台服务。已有旧版插件保持原安装来源；按安装说明升级后，在同一主机的新聊天中检查两个 Skill 和 MCP 加载状态。原生 Windows ACL、具体桌面版本的媒体展示和恢复体验分别验证。平台工具可提供的素材与检查能力，以当前目录为准。
