# 0.2.4 安装发现候选

本版本目前是可审源码与本地打包候选，尚未创建发行标签或发布 npm。main 的公开目录仍指向实际已发行的 0.2.3；本候选分支同步 package、lock、插件、目录和 CLIENT_VERSION，正式发行前再按发布手册合入并使用新的 creation-v0.2.4 标签。0.2.3 原包和标签不改。

- 安装前后从宿主本地 marketplace 索引发现全部相关目录，只做相关插件查询，无关远端目录不阻塞安装。
- 目录或读结果未知保持未知，保留版本/来源/Node/MCP/profile 验证；错误只报告安全阶段与退出事实。
- 宿主登记前持久保存精确 pending 身份，写回程未知后先观察原登记，不第二次 add 或自动补偿覆盖旧注册。
- 已安装、已启用、平台连接验证与当前聊天加载分开报告。在同一主机开 Local 新聊天或 CLI 新 session，复用 Token；纯 MCP 创作不需要产品仓或 Worktree。

候选使用隔离 HOME/CODEX_HOME/XDG、匿名本地 MCP 与替身 Codex CLI，经真实打包产物 npx/connect 检查。公共 registry 固定包、真实桌面新聊天的两个 Skill/MCP tools/list 与完整创作另行验收，不以候选测试代替。
