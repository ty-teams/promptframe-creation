# 0.3.11：本机账号目录与当前 Agent 选择

本机目录按平台和经认证的不可变账号身份分组，分别引用 Creation 与组件 CLI 已有授权，不复制 Token 或 Cookie。`accounts list` 显示安全摘要；`accounts refresh --profile <名称>` 验证并登记原 profile，不签发或轮换授权。

MCP 新增 `promptframe_local_accounts` 和 `promptframe_local_select_account`。选择前读取原安全配置并核对认证连接，选择只属于当前宿主会话，不改变其它 Agent、作品编辑权或已受理任务。切换前的在途调用保留原身份和回执，新账号的上传检查点按账号和宿主分开。

显式账号选择需要平台在 MCP initialize 返回 `experimental.promptframe.accountIdentity`。缺少该扩展的旧平台仍支持原 profile；缺少可核宿主身份、授权缺失或到期、凭据变化、目录不可读时明确说明原因，不借用其它账号权限。目录中的特殊文件会立即拒绝，不等待其写端。

完整格式、授权状态和多 profile 的选择见[本机账号目录](../local-account-directory.md)。实际宿主加载、原生 Windows ACL 以及组件 CLI 的对应功能按各自版本和实际验证记录核实。此版本不替换正在运行的桥，也不自动轮换凭据。
