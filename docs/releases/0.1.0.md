# 0.1.0 基础版

本版提供使用 PromptFrame 平台的本地 MCP 薄桥，适合开发者及已完成平台授权的用户。

- `setup`：规范化平台地址、安全输入创作 Token，保存到当前用户的受保护配置；有效凭据可复用。
- `status`：验证已保存的连接并读取当前工具目录。
- `bridge`：以 stdio MCP 接入客户端，转发平台动态工具及持久异步任务结果。
- 包内包含 `video-creation` Skill、Codex 插件 manifest 和 MCP 配置，并提供组件作者 CLI/Skill 文档链接。
- npm包依赖由标准npm安装处理；插件与Skill按README所述方式安装。

平台继续执行真实账号/项目权限、作品接管、制作确认、预算和账务。外部客户端停止等待不会自动取消已接受订单；未知结果先观察原任务。

本版仍需提供平台API地址、完成Token输入。多个聊天使用同一配置时共享客户端身份；分别控制作品应使用独立配置。新版自动会话隔离、一句话安装、自动升级和Studio活跃列表尚未在本版交付。原生Windows的凭据ACL尚未验证。

发行由 `creation-v0.1.0` 标签触发，公开安装状态以官方npm registry的该版本和integrity/provenance为准。GitHub源码、npm发行与平台/客户端实际安装分别确认。
